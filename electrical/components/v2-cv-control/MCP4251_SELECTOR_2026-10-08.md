# Independent manual/app CV selector

8 October 2026. Implementable prototype candidate, not approval to connect a
battery or energize the power stage. This supersedes the old MCP42100/two-range
and op-amp investigations for the next schematic increment. No extra range GPIO.

## Circuit

Keep the permanent 249k 0.1% upper resistor from receiver sense to BQ FB12.
Keep the manual 7.50k 0.1% plus 50k trimmer, returning to BQ FBG11. The trimmer
wiper is tied to its adjacent end as in the existing manual circuit.

Use a nonlatching Panasonic TQ2-3V DPDT relay. Manufacturer bottom-view drawing
is PDF page13 (index12): coil1/10; poleA NC2, COM3, NO4; poleB NC9, COM8, NO7;
5/6 unused. Do not confuse a latching or MBB variant with this part.

| Endpoint | Connection |

| K1 COM3 | BQ FB12 / permanent upper resistor lower end |

| K1 NO4 | Separate digital 7.50k 0.1%, then NX6008 drain3 |
| K1 COM8 | MCP4251 P1A7 and P1W6 tied |

GPIO20 is now **CV_AUTO_N**, active low. High or floating selects manual;
low selects digital. Remove the previous active-high/pulldown semantics.
The PMOS reuses the already accepted AO3401A model/part from logic power.
Prefer open-drain GPIO mode: released=manual, low=digital. Its physical boot
state must remain input/high-impedance; never enable an internal pulldown here.
GPIO20 is UART RX by default, not a strapping pin; no external UART transmitter
may drive this reserved selector node. Check EN, watchdog and software resets
individually: do not assume every reset type clears an output latch identically.
Using its switched rail for the NX gate avoids dependence on ESP GPIO VOH for
the analog MOSFET's gate overdrive. The coil provides a low-resistance gate
discharge path when the PMOS opens. Its negative flyback is diode-clamped.

MCP4251 pin11 ties VDD: manufacturer page1 says /WP, pin table says NC,
and section3.11 permits NC-to-VDD. No write-protect function is claimed.
Pin12 /SHDN ties VDD, CS1 has a pullup, SDO13 is NC in the three-wire interface.
Channel0 alone remains available on J7, labelled 50k. Remove the old external
channel1 header when integrating the internal path.

## Static results

Run `node electrical/v2/docs/calculations/cv-mcp4251-selector.mjs`.
128 bounded static endpoint cases pass. This is not a SPICE transient model.

For code d=0..256, A/W tied and B grounded:

```text
Rpot = RAB*d/256 + (Rw || (RAB*(256-d)/256))
Reff = Rpot || 110k
Vout = Vref * (1 + 249k/(7.50k + Rfet + Reff))
```

Nominal RAB50k/Rw75/Rfet4.8 at default reference1.536V gives code0=51.995V,
code128=15.232V and code256=10.668V. The fullscale resistance40k corner still
gets below12V: worst tested minimum-reference endpoint11.787V, including
divider/bleeder tolerances and +0.7% reference error. Fine trim is therefore
available when a particular board's highest-resistance endpoint needs it.

Across the tested component corners, the *lowest* maximum-reference ceiling
is51.083V. Typical upper endpoint with maximum trim is53.011V. This does NOT
support a guarantee of52V,54.6V or55V setpoints on every unit. In particular,
full13S lithium charging at54.6V is outside this implementation's supported
claim.12S50.4V is a more plausible high-voltage profile, pending calibration
and charger qualification. Code spacing is nonuniform and not every requested
voltage is exactly attainable; software must report the measured achievable
value below the receiver limit, not round upward to the requested value.

With the bottom rheostat shorted, or at its minimum, the fixed7.50k guard
limits the ideal static target to54.0369V using maximum reference1.566V,
+0.7% accuracy and adverse0.1% resistor errors. This covers ideal code0,
shutdown-to-B, and temporary grounded A/W states. It is not a55V transient
clamp and not a receiver-specific12/20/24V overvoltage protector.

## Power domains and sequencing

Manual mode is the original manufacturer-style divider using FBG. Digital
mode returns to ground: otherwise opening FBG could float the MCP terminals
up toward the receiver voltage. TI's explanation that FB is measured against
GND supports the measurement reference, but does not constitute TI approval
of this entire selector. Digital mode bypasses FBG's battery-drain-saving
switch. Its divider alone draws at most about215uA from55V (12mW), before
any BQ battery-discharge behavior described below. Normal12V regulation draws
approximately42uA through the upper divider. Relay adds approximately51mA
to3V3 without a series resistor. The final6.8ohm series resistor reduces this
to about46.4mA and0.153W total; include it in logic-power/backup-battery budgets.

When manual, the relay disconnects the digital branch and grounds its A/W
terminal. NX drain-to-source orientation blocks positive high voltage with
the gate off. When powered digital mode encounters a55V battery but a much
lower setpoint, NX operates as a source follower, preventing its source from
simply following the high FB voltage. Its drain may then approach55V, so the
selected device is60V rated. Do not treat this as a60V system rating or an
unconditional all-temperature analog voltage guarantee.

For normal regulated operation, even a3.0V rail and approximately1.4V maximum
source voltage leave about1.6V gate drive after the small PMOS drop. NX has a
4.8ohm maximum at VGS1.5V, ID10mA,25C. Its room-temperature off leakage maximum
is1uA at60V:110k bleeder limits the corresponding ideal unpowered-node rise
to0.1111V before the relay returns. Hot leakage has no equivalent maximum
in the retrieved table and must be characterized.
The >=3.0V condition matters with the optional1S cell and LDO: a depleted cell
can lower the rail before the MCP reaches its2.7V analog minimum. Below3.0V,
do not claim the calculated NX on-resistance bound. Early exit-to-manual or
explicit low-rail characterization is required; no rail-monitor feature is
implied by this document.

The dual Schottky clamp routes positive transients into3V3 and negative
transients toward GND;10k rail bleed
prevents tiny leakage currents holding the rail up indefinitely. Clamp reverse
leakage injects current from3V3 into the lower leg and therefore LOWERS the
regulated target. Conversely, lower-diode reverse leakage removes current
and RAISES the target; calibration must include the net leakage and temperature.
The positive-node static guard bound remains, but no signed leakage benefit
can be promised for the dual clamp. BAT54 maximum0.24V at100uA is a25C condition, not a guarantee
that arbitrary transient current stays below the MCP's VDD+0.3V absolute limit.
There is no intentional negative DC source in this branch, but relay switching
and gate/coil coupling can produce negative spikes. Scope both polarities.
The dual clamp replaced the earlier upper-only diode after the robustness pass:
NX typical gate-source capacitance is about25pF and MCP W capacitance120pF,
so a several-volt gate fall can inject a significant sub-microsecond negative
step near code0. Those typical capacitances are a warning, not a peak guarantee.

Required software sequence for intentional handover: disable BQ charging over
I2C; select an appropriate MCP code and terminal configuration; change selector;
wait for contact settling; restore/verify BQ reference and the intended target;
only then enable charging within the receiver's configured current/voltage limits.
POR code128 is about15.23V nominal, not the manual12V setting, so do not switch
to it blindly. Readback is physical BQ telemetry, not unwired MCP SDO.

On reset or power loss, PMOS should switch off, NX gate falls, FB rises through
the upper resistor to stop switching, and relay NC eventually restores manual.
**Not yet proven:** ordering during rail collapse. Below2.7V the MCP analog
behavior is unspecified, before its own BOR. A temporary low resistance can
command the hardware maximum while the relay has not returned. Relay pole
skew/bounce can also temporarily ground A/W while the FB pole is digital.
Neither the transistor nor the static54V guard proves a20V receiver survives
this event. Bench tests must cover abrupt rail short, slow brownout, reset,
contact bounce, hot/cold and every relevant receiver voltage before claiming
safe receiver failover. If inadequate, add a power-good interlock with measured
timing; an untested supervisor alone does not prove abrupt-collapse protection.

BQ remains powered independently of ESP. Reference fine trim survives ESP loss:
a manual12V setting calibrated at1.536V becomes about12.234V if BQ retains
1.566V. Also a high-voltage attached battery with manual12V target triggers BQ
BAT_OVP behavior: switching stops and the IC's output-discharge load can turn
on. Datasheet gives16mA typical, about0.88W at55V, with no maximum stated in
that table. This is a thermal/use-case gate, not harmless indefinite idle.

## Robustness review and scope matrix

The second review preserved the architecture and corrected three details,
approved by the coordinating owner: 100 ohm GPIO series resistor, 6.8 ohm
coil series resistor, and dual-polarity analog clamp. No extra GPIO or IC.

- The 100 ohm / 10k gate network gives at least 2.673 V PMOS gate drive at a
  3.0 V rail, ESP VOL=0.1*VDD and adverse 1% resistor errors. The earlier 1k
  series resistor gave only 2.455 V, below the AO3401A's 2.5 V RDS test point.
- Direct coil drive at 3.3 V would be 51.32 mA nominal, or 57.02 mA with
  coil resistance -10%, approximately 169/188 mW. Although below the stated
  150% maximum voltage at 20 C, it misses Panasonic's +/-5% operating advice.
  With 6.8 ohm series and 0.085 ohm PMOS, nominal coil voltage is 2.981 V at
  46.36 mA. Eight corners for a 3.3 V +/-2% rail, +/-10% coil and +/-1%
  series resistor give 2.887-3.070 V coil and at most 52.04 mA supply current.
  At a 3.0 V rail the minimum calculated coil voltage is 2.678 V, above the
  2.25 V maximum *initial 20 C* pickup threshold. That does not establish
  hot/cold pickup, aged contact timing or pickup with an unspecified rail.
- Manufacturer page6 (printed5) gives operate/release maxima of 3 ms at rated
  coil voltage and 20 C, excluding bounce; release also excludes a diode.
  Our flyback diode extends decay. Do not use 3 ms as a guaranteed settling
  delay or claim simultaneous poles: no pole-skew maximum was found.
- With stable 3V3, GPIO release removes drive before mechanical release;
  this favors a stop interval. In a slow rail fall, the MCP can leave its
  specified analog region below 2.7 V while the relay remains energized.
  Internal MCP BOR is no substitute for a 2.7 V power-good interlock.
- Pole A digital while pole B NC grounds the rheostat and requests the
  hardware ceiling when NX is on. Pole A open raises FB and suppresses
  switching. Pole A manual disconnects digital regardless of pole B.
  The exact duration and converter response remain measurement gates.

Suggested future scope tests, not permission to energize this board: first
verify continuity, polarity and selector behavior with the main power stage
disabled. Advance only under a separately reviewed, energy-limited bench plan
using dummy loads/receiver emulation, not a bicycle generator or lithium pack.

| Test group | Variations | Required observations |
|---|---|---|
| Static selector | Manual/digital; code0/128/256 and intended profiles | NC/NO endpoints, actual output, MCP A/W, divider current |
| Intentional handover | Both directions, different manual/app targets; BQ disabled first | Both relay poles, FB, coil and NX gate; measured bounce/settling |
| Reset | EN, watchdog, software reset, USB flash/download mode | GPIO20 released throughout boot; no digital selection before configuration |
| Supply failure | Fast disconnection/controlled rail collapse, slow ramp, recovery; optional-cell low rail | 3V3 crossing 3.0/2.7 V, GPIO20, NX gate, A/W relative to both rails, output peak |
| Power ordering | Main input/receiver before USB; USB before main; receiver emulated up to working ceiling | No analog backfeed; FBG-opening behavior; no unintended boost/reverse operation |
| Retained state | Minimum/default/maximum BQ trim, MCP near minimum and POR code | Correct manual fallback with retained trim; BQ OVP/discharge flags/current |
| Environmental | Cold/room/hot within intended component envelope; repeated cycles and light/heavy dummy load | Coil pickup/release, leakage-induced CV drift, oscillation, junction/case heating |

Capture fast spikes and millisecond contact motion separately. Probe the
low-voltage node at the MCP pins with short ground connections; use appropriately
rated differential/isolated probing for high-voltage or switching nodes, never
a grounded scope clip on a switch node. Measure A/W minus actual VDD as well
as A/W minus GND. Acceptance requires analog voltages/currents within datasheet
limits with margin and receiver voltage never exceeding its own limit; a
trace below 55 V alone is insufficient for a 20 V receiver. Preserve waveforms,
temperature, code/trim and receiver/load settings. Any failed case keeps that
mode gated, rather than being waived by the static resistor calculation.
