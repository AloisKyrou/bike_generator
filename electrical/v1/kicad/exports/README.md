# Generated KiCad outputs

This directory is reserved for review and manufacturing exports generated from
the versioned KiCad sources, for example:

```text
review/
gerbers/
drill/
bom/
pick-and-place/
step/
```

Generated files are ignored by Git by default. A release archive may be attached
to a tagged revision later, after ERC, DRC and a human pre-fabrication review.
